Train and predict¶

Three calls take you from a data file to a reusable model, predictions and an evaluation report. No dictionary file or manual TSV export is needed:

from khiops_duckdb import deploy_model, evaluate_predictor, train_predictor

report, model = train_predictor(
    "train.parquet", target="target", output_dir="results/train",
)
predictions = deploy_model(
    "test.parquet", model=model, output_dir="results/predict",
)
evaluation = evaluate_predictor(
    "test.parquet", model=model, output_dir="results/evaluate",
)

Replace "target" with the column you want to predict. The returned values are paths to the saved report, model and output files. Without output_dir, each call creates a unique folder in khiops-results/.

Native Khiops options work as keyword arguments, for example max_cores=1. You keep the standard Khiops reports and model files, not a new model format. The same file-or-relation interface supports recoding, coclustering, and all other table-based core tasks; see API reference.

For database tables, SQL queries or multiple tables, see Data sources.
