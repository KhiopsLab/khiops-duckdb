API reference¶

Functions you call. Objects you configure. Files you keep. Import high-level functions from khiops_duckdb or khiops_duckdb.core.

Sources Training Deployment Table utilities Advanced

Shared arguments¶

All high-level functions accept:

  • source: a path, URL, file glob, DuckDB relation, Source or Table.

  • connection=None: an existing DuckDB connection for file readers, extensions and credentials. It stays open after the call.

  • output_dir=None: where default output files are saved. Without it, each file-producing call creates a unique directory under khiops-results/. Explicit native output paths take precedence.

  • **options: native Khiops task options. The signatures below expand the task-specific keywords you will usually need.

Training, model deployment and evaluation also accept additional_tables={path: source, ...} where the native task supports it. See Data sources for keys and multi-table schemas.

target aliases target_variable; model aliases dictionary_file_path_or_domain. Supply only one spelling. An ambiguous model dictionary needs an explicit dictionary_name. Input-format arguments are managed by the bridge; file-reader settings belong in Source.

Outputs survive the call; temporary input files do not. Native errors propagate.

Configure a source¶

Most calls only need a filename. Use Source when you need keys, type overrides or reader options:

from khiops_duckdb import Source

customers = Source("customers.parquet", key=("id",))
comments = Source("comments.csv", types={"body": "Text"})
export = Source("data.export", format="csv", options={"delimiter": "|"})
class Source(data, key=(), types=<factory>, entity=False, format=None, options=<factory>)¶

Décrit une source fichier ou une relation et son schéma Khiops.

Parameters:

  • data (str | PathLike[str] | DuckDBPyRelation) – Chemin, URL, motif de fichiers ou relation DuckDB.

  • key (Sequence[str]) – Colonnes de clé, dans l’ordre de la hiérarchie.

  • types (Mapping[str, Literal['Categorical', 'Numerical', 'Text', 'Date', 'Time', 'Timestamp']]) – Types Khiops à imposer à certaines colonnes.

  • entity (bool) – Relation un-à-un avec le parent.

  • format (Literal['csv', 'json', 'parquet'] | None) – Format explicite pour les fichiers sans extension reconnue.

  • options (Mapping[str, Any]) – Options transmises au lecteur DuckDB, sans modification.

types accepts Categorical, Numerical, Text, Date, Time and Timestamp. format is "csv", "json" or "parquet". The default mappings are independent empty dictionaries for each instance.

Train models¶

train_predictor(source, *, target, output_dir=None, **options) → tuple[str, str | None]¶

Train a supervised predictor, or prepare data without a target.

Parameters:

target – Target column name. Use "" for unsupervised preparation.

Returns:

(report_path, model_path). The model path is None when the target is empty.

report, model = train_predictor(
    "train.parquet", target="churn", output_dir="results/train",
    max_cores=1,
)
train_recoder(source, *, target='', output_dir=None, **options) → tuple[str, str]¶

Train a recoding model for transforming data into engineered features. Omitting target runs an unsupervised recoding workflow.

Returns:

(report_path, recoder_dictionary_path). Use deploy_model() to apply the recoder.

train_coclustering(source, *, coclustering_variables, output_dir=None, **options) → str¶

Discover groups across two to ten selected variables.

Parameters:

coclustering_variables – List of column names to cocluster.

Returns:

Coclustering report path (.khcj).

train_instance_variable_coclustering(source, *, output_dir=None, **options) → str¶

Train an instance-variable coclustering model.

Returns:

Coclustering report path (.khcj).

Predict and evaluate¶

model accepts a dictionary path, Path or native DictionaryDomain. The unique root dictionary, or the only dictionary, is selected automatically.

deploy_model(source, *, model, output_dir=None, **options) → str¶

Apply a saved predictor, recoder or other native deployment dictionary.

Parameters:

model – Model dictionary returned by training.

Returns:

Deployed table path (TSV by default).

predictions = deploy_model(
    "test.parquet", model=model, output_dir="results/predict",
)
evaluate_predictor(source, *, model, output_dir=None, **options) → str¶

Evaluate a trained predictor on labeled data.

Parameters:

model – Predictor dictionary.

Returns:

Evaluation report path (.khj).

The source must contain the target column. dictionary_name also accepts the native spelling train_dictionary_name for this function.

deploy_predictor_for_metrics(source, *, model, output_dir=None, **options) → str¶

Export predictor output columns for metric computation.

Returns:

Metrics table path.

deploy_coclustering(source, *, coclustering_file_path, key_variable_names, deployed_variable_name, output_dir=None, **options) → tuple[str, str]¶

Apply a trained coclustering and create its deployment dictionary.

Parameters:

  • coclustering_file_path – Coclustering report produced by training.

  • key_variable_names – Names of the categorical key columns.

  • deployed_variable_name – Coclustering variable to deploy.

Returns:

(deployed_table_path, deployment_dictionary_path).

Input must be sorted lexically by the key variables. Use a sorted DuckDB relation for repeated observations; do not declare a unique main-table key. This task does not accept additional tables.

Inspect and prepare tables¶

build_dictionary_from_data_table(source, *, output_dictionary_name='main_table', output_dir=None, **options) → str¶

Ask Khiops to infer a dictionary from the exported table.

Returns:

Dictionary file path (.kdic).

This native task re-infers the snapshot; source keys and type overrides are not a substitute for configuring the resulting dictionary.

check_database(source, *, model=None, **options) → None¶

Validate data against a dictionary. Without model, use the dictionary inferred from the source.

Returns:

None. Native validation errors propagate.

sort_data_table(source, *, sort_variables=None, output_dir=None, **options) → str¶

Sort by sort_variables or by the supplied dictionary’s keys.

Returns:

Sorted table path.

extract_keys_from_data_table(source, *, output_dir=None, **options) → str¶

Extract key columns from a keyed Source/Table or native dictionary.

Returns:

Keys table path.

detect_data_table_format(source, **options) → tuple[bool | None, str | None]¶

Detect the format of the normalized TSV snapshot, not the original source.

Returns:

(header_line, field_separator); values may be None when detection cannot determine them.

Native APIs without data-table inputs, including dictionary/report readers, simplify_coclustering and interpret_predictor, remain available unchanged through khiops_duckdb.core.

Advanced: explicit snapshots¶

Use these objects when you need to reuse a snapshot or edit its dictionary. Most workflows should use the high-level functions above.

class Table(relation, key=(), types=<factory>, entity=False)¶

Décrit une table et ses clés de jointure.

Parameters:

  • relation (DuckDBPyRelation) – Relation appartenant à une connexion DuckDB ouverte.

  • key (Sequence[str]) – Colonnes de clé, dans l’ordre de la hiérarchie Khiops.

  • types (Mapping[str, Literal['Categorical', 'Numerical', 'Text', 'Date', 'Time', 'Timestamp']]) – Types Khiops à imposer à certaines colonnes.

  • entity (bool) – Relation un-à-un avec le parent, au lieu d’un-à-plusieurs.

materialize(main_table, *, additional_tables=None, directory=None)¶

Exporte les relations une seule fois vers des fichiers TSV temporaires.

Parameters:

  • main_table (Table | DuckDBPyRelation) – Relation principale ou description complète de la table.

  • additional_tables (Mapping[str, Table] | None) – Tables par chemin Khiops, par exemple orders/items.

  • directory (str | PathLike[str] | None) – Répertoire parent existant pour le sous-répertoire temporaire.

Yields:

Dataset utilisable avec les API natives de Khiops.

Raises:

  • TypeError – Relation ou type DuckDB non pris en charge.

  • ValueError – Schéma, hiérarchie, clé ou valeur numérique non valide.

  • duckdb.Error – Lecture de source, conversion ou écriture impossible.

Return type:

Iterator[Dataset]

class Dataset¶

Returned by materialize; not intended for direct construction. dictionary_domain exposes the generated dictionary. data_table_path and additional_data_tables expose temporary file paths, valid only inside the materialization context.

core_args¶

Retourne les arguments natifs de khiops.core, sans wrapper de tâche.

table_args¶

Retourne les arguments des tables, utilisables avec un modèle existant.

to_sklearn()¶

Charge les fichiers en mémoire pour l’interface scikit-learn.

Returns:

Spécification Khiops contenant des DataFrames pandas indépendants. Les dates et heures restent des chaînes.

Raises:

ValueError – Khiops réinterpréterait les clés multi-table à la prédiction.

Return type:

SklearnDataset
